## 📖 Tentang Repository

Repository ini digunakan untuk menyimpan source code dan dokumentasi tugas pada mata kuliah **Desain dan Pemrograman Web**.

Project yang dikembangkan adalah **SIMPUS-Mini (Sistem Informasi Perpustakaan Mini)** yang digunakan untuk menampilkan dan mengelola data buku serta anggota perpustakaan.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** — Membuat struktur halaman web menggunakan elemen semantic.
- **CSS3** — Mengatur tampilan, warna, layout, tabel, form, dan komponen halaman.
- **JavaScript** — Digunakan untuk menambahkan fungsi dan interaksi pada halaman web.
