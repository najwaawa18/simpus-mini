## Penjelasan `index.html`

| Kode | Penjelasan |
|---|---|
| `<!DOCTYPE html>` | Mendeklarasikan bahwa dokumen menggunakan HTML5. |
| `<html lang="id">` | Membuka dokumen HTML dan menentukan bahasa halaman sebagai Bahasa Indonesia. |
| `<head>` | Membuka bagian head yang berisi informasi dan pengaturan dokumen. |
| `<meta charset="UTF-8">` | Menentukan encoding karakter UTF-8 agar karakter dapat ditampilkan dengan benar. |
| `<title>SIMPUS-Mini \| Beranda</title>` | Menentukan judul halaman yang ditampilkan pada tab browser. |
| `<link rel="stylesheet" href="assets/style.css">` | Menghubungkan halaman HTML dengan file CSS `style.css` yang berada di dalam folder `assets`. |
| `</head>` | Menutup bagian head. |
| `<body>` | Membuka bagian body yang berisi seluruh konten yang ditampilkan pada halaman. |
| `<header>` | Membuka elemen semantic header sebagai bagian kepala halaman. |
| `<h1>SIMPUS-Mini</h1>` | Menampilkan judul utama aplikasi SIMPUS-Mini. |
| `<nav>` | Membuka elemen semantic nav yang digunakan untuk bagian navigasi halaman. |
| `<ul>` | Membuat daftar tidak berurutan untuk menampung menu navigasi. |
| `<li><a href="index.html">Beranda</a></li>` | Membuat menu Beranda yang mengarah ke halaman `index.html`. |
| `<li><a href="buku/list.html">Daftar Buku</a></li>` | Membuat menu Daftar Buku yang mengarah ke halaman `list.html` di dalam folder `buku`. |
| `<li><a href="buku/tambah.html">Tambah Buku</a></li>` | Membuat menu Tambah Buku yang mengarah ke halaman `tambah.html` di dalam folder `buku`. |
| `<li><a href="anggota/list.html">Daftar Anggota</a></li>` | Membuat menu Daftar Anggota yang mengarah ke halaman `list.html` di dalam folder `anggota`. |
| `</ul>` | Menutup daftar menu navigasi. |
| `</nav>` | Menutup elemen navigasi. |
| `</header>` | Menutup bagian header. |
| `<main>` | Membuka elemen semantic main sebagai bagian utama halaman. |
| `<section>` | Membuka section pertama untuk mengelompokkan informasi sambutan. |
| `<h2>Selamat Datang di Sistem Perpustakaan Mini</h2>` | Menampilkan judul bagian sambutan. |
| `<p>Aplikasi sederhana untuk mengelola data buku dan anggota perpustakaan.</p>` | Menampilkan deskripsi singkat mengenai fungsi aplikasi. |
| `</section>` | Menutup section pertama. |
| `<section>` | Membuka section kedua yang digunakan untuk menampilkan ringkasan statistik. |
| `<h2>Ringkasan</h2>` | Menampilkan judul bagian ringkasan. |
| `<article>` | Membuka elemen semantic article untuk menampilkan satu informasi statistik. |
| `<h3>Total Buku</h3>` | Menampilkan judul statistik jumlah total buku. |
| `<p>10</p>` | Menampilkan jumlah total buku, yaitu 10. |
| `</article>` | Menutup article statistik Total Buku. |
| `<article>` | Membuka article untuk menampilkan informasi jumlah anggota. |
| `<h3>Total Anggota</h3>` | Menampilkan judul statistik jumlah total anggota. |
| `<p>7</p>` | Menampilkan jumlah total anggota, yaitu 7. |
| `</article>` | Menutup article statistik Total Anggota. |
| `<article>` | Membuka article untuk menampilkan informasi buku yang sedang dipinjam. |
| `<h3>Sedang Dipinjam</h3>` | Menampilkan judul statistik jumlah buku yang sedang dipinjam. |
| `<p>3</p>` | Menampilkan jumlah buku yang sedang dipinjam, yaitu 3. |
| `</article>` | Menutup article statistik buku yang sedang dipinjam. |
| `</section>` | Menutup section ringkasan. |
| `</main>` | Menutup bagian utama halaman. |
| `<footer>` | Membuka elemen semantic footer sebagai bagian kaki halaman. |
| `<p>&copy; 2026 SIMPUS-Mini &mdash; Jobsheet 1</p>` | Menampilkan informasi hak cipta, tahun pembuatan, nama aplikasi, dan keterangan Jobsheet 1. |
| `</footer>` | Menutup bagian footer. |
| `</body>` | Menutup bagian body dokumen HTML. |
| `</html>` | Menutup keseluruhan dokumen HTML. |
