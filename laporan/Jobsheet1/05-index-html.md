🏠 5. index.html — Beranda

| Kode | Penjelasan |
|---|---|
| `<!DOCTYPE html>` | Mendeklarasikan dokumen menggunakan HTML5. |
| `<html lang="id">` | Membuka dokumen HTML dan menentukan bahasa halaman sebagai Bahasa Indonesia. |
| `<head>` | Membuka bagian head dokumen. |
| `<meta charset="UTF-8">` | Menentukan encoding karakter UTF-8. |
| `<title>SIMPUS-Mini \| Beranda</title>` | Menentukan judul halaman pada tab browser. |
| `</head>` | Menutup bagian head. |
| `<body>` | Membuka bagian body yang berisi seluruh konten halaman. |
| `<header>` | Membuka elemen semantic header sebagai bagian kepala halaman. |
| `<h1>SIMPUS-Mini</h1>` | Menampilkan judul utama aplikasi SIMPUS-Mini. |
| `<nav>` | Membuka elemen navigasi halaman. |
| `<ul>` | Membuat daftar tidak berurutan untuk menu navigasi. |
| `<li><a href="index.html">Beranda</a></li>` | Membuat menu Beranda menuju halaman utama. |
| `<li><a href="buku/list.html">Daftar Buku</a></li>` | Membuat menu menuju halaman Daftar Buku. |
| `<li><a href="buku/tambah.html">Tambah Buku</a></li>` | Membuat menu menuju halaman Tambah Buku. |
| `<li><a href="anggota/list.html">Daftar Anggota</a></li>` | Membuat menu menuju halaman Daftar Anggota. |
| `</ul>` | Menutup daftar menu navigasi. |
| `</nav>` | Menutup elemen navigasi. |
| `</header>` | Menutup bagian header. |
| `<main>` | Membuka konten utama halaman. |
| `<section>` | Membuka section untuk bagian sambutan. |
| `<h2>Selamat Datang di Sistem Perpustakaan Mini</h2>` | Menampilkan judul sambutan pada halaman utama. |
| `<p>Aplikasi sederhana untuk mengelola data buku dan anggota perpustakaan.</p>` | Menampilkan deskripsi singkat mengenai fungsi aplikasi. |
| `</section>` | Menutup section sambutan. |
| `<section>` | Membuka section untuk ringkasan statistik. |
| `<h2>Ringkasan</h2>` | Menampilkan judul bagian ringkasan. |
| `<article>` | Membuka elemen article untuk informasi statistik pertama. |
| `<h3>Total Buku</h3>` | Menampilkan label jumlah total buku. |
| `<p>10</p>` | Menampilkan jumlah buku sebanyak 10. |
| `</article>` | Menutup article statistik total buku. |
| `<article>` | Membuka article untuk statistik anggota. |
| `<h3>Total Anggota</h3>` | Menampilkan label jumlah total anggota. |
| `<p>7</p>` | Menampilkan jumlah anggota sebanyak 7. |
| `</article>` | Menutup article statistik total anggota. |
| `<article>` | Membuka article untuk statistik buku yang sedang dipinjam. |
| `<h3>Sedang Dipinjam</h3>` | Menampilkan label jumlah buku yang sedang dipinjam. |
| `<p>3</p>` | Menampilkan jumlah buku yang sedang dipinjam sebanyak 3. |
| `</article>` | Menutup article statistik peminjaman. |
| `</section>` | Menutup section ringkasan. |
| `</main>` | Menutup konten utama halaman. |
| `<footer>` | Membuka bagian footer halaman. |
| `<p>&copy; 2026 SIMPUS-Mini &mdash; Jobsheet 1</p>` | Menampilkan informasi hak cipta dan keterangan Jobsheet 1. |
| `</footer>` | Menutup bagian footer. |
| `</body>` | Menutup bagian body dokumen. |
| `</html>` | Menutup dokumen HTML. |
